# 보고서 "항목 하나 = 상자 하나" 정리 (짧은 설계)

작성일: 2026-11-22 · 규모: 작은~중간 변경 (화면만, 서버·결과 형식 변경 없음)

## 목적
점검 보고서에서 같은 항목이 표·콘솔·요약 상자로 흩어지고(요약은 맨 뒤), 같은 내용이 별도 카드·역할 요약 표·상세 칸에 최대 세 번 나온다. 항목마다 상자 하나에 **상태(요약)와 결과를 함께** 보여 주고 중복을 없앤다(사용자 요청, 역할 부분 포함).

## 설계 (사용자 승인)
- **항목 상자**: 제목 줄 = 항목 이름 + 상태 배지(요약), 요약 메시지가 있으면 제목 아래 한 줄, 그 아래 표·콘솔·측정값·로그 표. 내용 블록이 둘 이상일 때만 작은 소제목. `· 요약` 상자 없음.
- **공통 부분**
  - 프로세스·디스크·디렉터리·파일 크기·포트·HTTP: 항목 상자 안에 기존 상세 표(이전 점검 비교 ▲▼ 포함)를 넣고, 아래 별도 카드는 숨긴다. 그 항목 상자가 없는 예전 결과는 별도 카드를 그대로 보인다.
  - 서버 정보·CPU·메모리·가동시간: "서버 정보"·"자원 사용량 요약" 카드가 이미 비교까지 보여 주므로 항목 상자를 만들지 않는다.
  - 카드 제목 "기본 정책 사용자 항목" → "점검 항목별 결과".
- **역할 부분**
  - "○○ 고유 점검" 요약 표는 역할 항목이 있으면 숨긴다(상태는 상자 제목 옆).
  - WEB 엔진 상태 상자 ← WebtoB wsadmin 결과(구문 강조 콘솔, 일반 콘솔 대신), JVM Heap 상자 ← JVM Heap 상세 표(일반 표 대신), DB 인스턴스·접속 상자 ← DB 엔진·데이터베이스 상세(쿼리 표 앞에). 옮긴 원래 칸은 숨긴다.
  - "현재 자동 수집되지 않는 항목" 표는 그대로.
- 인쇄도 같은 구조. 이전 점검 비교를 바꿔 다시 그려도 옮긴 표가 사라지지 않아야 한다.
